02 — About

Draws First.
Generates Second.

I'm Ben — a character designer and art director out of Toronto. I started with pencils and I still start with pencils: the silhouette, the weight, the face — that's all hand-drawn. Then my local GenA.I stack takes the sketch and iterates on it at a speed that used to take a whole studio week. Every model runs on my own machine, so nothing leaves the studio and the client's IP never touches a cloud.

The result is a faster, cheaper, fully private pipeline — but the character still feels human because it began with a human. That's the whole pitch.
